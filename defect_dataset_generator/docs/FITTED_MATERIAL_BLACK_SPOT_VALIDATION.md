# Fitted Material Black-Spot Validation

## Purpose

This validation checks whether a visually fitted material calibration can be passed into the first production `black_spot` backend and whether the generated images look visually improved compared with the backend default material.

This is not a training or mAP validation. It only compares rendered appearance.

## Backend Material Input

Backend script:

```text
E:\BlenderProject\BlenderProc\examples\my_project\reference_blend_blackdot_multi_model.py
```

Before this task, the backend did not read external material JSON. It used preset material setup:

- `QC71336_white`: authored white material from the appended model, tuned by `tune_prebuilt_white_materials`.
- `QC71336_gray`: explicit gray override material.
- `P101040_blue` and `QC75244_white`: explicit backend material assignment helpers.

The backend now supports optional:

```text
--material_json <best_material.json>
```

The loader supports both:

- old flat material JSON files
- schema `0.2` visual calibration files with `material_parameters`, `scene_calibration`, and `scoring`

Only `material_parameters` are used for object material rendering. `scene_calibration` is recorded only, and `scoring` fields are not used for rendering.

## Validation Result

Both batches used the same seeds:

```text
300, 301, 302, 303, 304
```

Both batches succeeded:

| Batch | Requested | Succeeded | Failed | Material override |
| --- | ---: | ---: | ---: | --- |
| default_material | 5 | 5 | 0 | false |
| fitted_material | 5 | 5 | 0 | true |

Per-sample framework quality checks passed for both batches:

- RGB exists and is readable.
- Mask exists and is readable.
- YOLO label exists and is non-empty.
- Per-image metadata exists.
- RGB and mask image sizes match.
- YOLO bbox values are within `0-1`.
- YOLO label matches backend bbox.

## Side-by-Side Observations

- The fitted material render is cooler and slightly brighter than the default backend material.
- This direction matches the fitted calibration output, especially `base_color: [0.76, 0.8, 0.86, 1.0]`.
- The fitted material override preserves black spot placement, masks, and YOLO labels because the same seed range was used.
- The fitted material appears closer in white/cool tone to the chosen real reference than the previous default, but background and lighting are still not fully calibrated.
- The defect itself remains generated by the existing backend; this task did not change black-spot geometry or label logic.

## Limitations

- This validates visual appearance only, not detector performance.
- Scene calibration fields from `best_material.json` are not applied by this backend yet.
- The current comparison uses one real reference photo and count `5`; it should be repeated on more references before treating the fitted material as a default production profile.
- The fitted material is a visual calibration, not physically accurate BRDF recovery.
